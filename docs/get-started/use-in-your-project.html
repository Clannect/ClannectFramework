Use CFW in your project

Add CFW to a CMake project from source with FetchContent, or install a release and let find_package find it.

From source, with FetchContent

CMake downloads CFW and builds it as part of your project:

include(FetchContent)
FetchContent_Declare(
    ClannectFramework
    GIT_REPOSITORY https://github.com/Clannect/ClannectFramework.git
    GIT_TAG        main   # or a specific commit
)
FetchContent_MakeAvailable(ClannectFramework)

target_link_libraries(my_app PRIVATE cfw::app)   # or cfw::core, cfw::net, cfw::text...

As a subproject, CFW builds only its libraries: no tests, examples or benchmarks.

Tip

Set GIT_TAG to a specific commit or release tag. CFW is pre-1.0 and its API may change between versions, so main can break your build on any day.

From a release

Prebuilt packages are on the Releases page.

Windows

There are two installers:

  • The online installer downloads the version you choose, and can tell you when a new one is released.
  • A version's offline installer has everything inside and needs no internet.

Both can register the install with CMake, so find_package finds it with no path to set. A zip of the Windows package is on the Releases page too.

Linux and macOS

Unpack the package for Linux x64, or for macOS on Apple silicon (experimental), and point CMake at the folder:

cmake -S . -B build -DCMAKE_PREFIX_PATH=/path/to/unpacked/folder

In your CMakeLists.txt

find_package(ClannectFramework 0.2 REQUIRED)
target_link_libraries(my_app PRIVATE cfw::app)

The packages also contain cfw-ui-gallery, a tour of the widgets.

Which target to link

Each module is a CMake target named cfw::<name>, and linking one brings in the modules it depends on. Link the highest one you use:

You are writingLink
A desktop application with windows and widgetscfw::app
A headless servercfw::net, and cfw::io for files and JSON (each brings cfw::core)
A tool that reads files, JSON or zip archivescfw::io
Something that only plays or decodes soundcfw::audio

See Modules and platforms for the whole list.
