Build and run the tests

Clone the repository, configure it with a CMake preset, build it, and run the test suite.

What you need

  • CMake 3.25 or newer.
  • Ninja.
  • A C++20 compiler: GCC 13 (MinGW-w64 on Windows) or Clang 18.

Nothing else is needed to build. CFW links only the C++ standard library and the operating system.

Linux

Install the X11 development headers (libx11-dev on Debian and Ubuntu) to get windows. Without them, CFW builds a headless stub.

Build

git clone https://github.com/Clannect/ClannectFramework.git
cd ClannectFramework
cmake --preset debug
cmake --build --preset debug

The debug preset is the one for everyday work: it turns on contract checks and bounds-checked containers. The other presets are listed in Build presets.

Run the tests

ctest --preset debug

Every test should pass. Warnings are errors in CFW's own code, so a clean build is also a build with no warnings.

Try the widget gallery

The gallery is a tour of the widgets in cfw-ui. After a debug build it is here:

build/debug/examples/cfw-ui-gallery

Optional libraries at run time

On Linux, CFW loads two system libraries when the program runs, if they are installed, and does without them otherwise. Both are on every desktop system.

LibraryUsed for
libasound.so.2Sound output.
libXi.so.6Relative mouse mode and touch.
