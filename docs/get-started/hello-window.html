Hello, window

A first program: a window with a label and a button that counts its clicks.

The program

#include <cstdio>
#include <string>

#include "cfw/app/UiWindow.h"
#include "cfw/ui/Controls.h"

using namespace cfw;

int main() {
    auto created = UiWindow::create({"Hello, CFW", {480, 320}}, Theme::dark().withSystemFonts());
    if (!created) {
        std::fprintf(stderr, "no window: %s\n", created.error().message().c_str());
        return 1;
    }
    UiWindow &window = *created.value();

    auto &column = window.surface().root().add<Stack>(Stack::Direction::Column, 12.0f, 24.0f);
    auto &label = column.add<Label>("Hello from Clannect Framework");
    auto &button = column.add<Button>("Click me");

    int clicks = 0;
    ScopedConnection onClick = button.clicked.connect([&] {
        label.setText("Clicked " + std::to_string(++clicks) + " times");
    });

    runUntilClosed(window);
}

Link it against cfw::app, as shown in Use CFW in your project.

What each part does

Create the window

auto created = UiWindow::create({"Hello, CFW", {480, 320}}, Theme::dark().withSystemFonts());

UiWindow is a native window that shows a tree of widgets. It takes a title, a size, and a theme. Theme::dark() is the palette of Clannect's editor; there is a Theme::light() too. A theme has no fonts until you ask for them: withSystemFonts() gives it the platform's interface font.

Check that it worked

if (!created) {
    std::fprintf(stderr, "no window: %s\n", created.error().message().c_str());
    return 1;
}

Creating a window can fail, for example on a machine with no display. CFW does not throw for errors: create returns a Result, which holds either the window or an Error that says why not. See Errors and Result.

Add the widgets

auto &column = window.surface().root().add<Stack>(Stack::Direction::Column, 12.0f, 24.0f);
auto &label = column.add<Label>("Hello from Clannect Framework");
auto &button = column.add<Button>("Click me");

A Stack lays its children out in a row or a column. Here it is a column with a spacing of 12 between the children and a padding of 24 around them. add<T>(...) creates a widget inside its parent and returns a reference to it; the parent owns it.

React to the click

ScopedConnection onClick = button.clicked.connect([&] {
    label.setText("Clicked " + std::to_string(++clicks) + " times");
});

clicked is a signal: connect a function to it and the button calls the function on every click. The ScopedConnection disconnects when it goes out of scope, so the function is never called after clicks and label are gone. See Signals.

Run

runUntilClosed(window);

This handles events and paints frames until the window is closed.
