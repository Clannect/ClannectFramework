The first public release of **Clannect Framework**: a C++20 application framework with no third-party
dependencies. Windows, text, images, networking and a widget toolkit, written from scratch and tested against
the reference implementations. See the [README](https://github.com/Clannect/ClannectFramework#readme) to get
started.

This is a **pre-1.0** release: CFW runs Clannect today, but the API may change between versions.

## Downloads

| File | What it is |
|---|---|
| `ClannectFramework-0.1.0-windows-x64-mingw.zip` | Headers, static libraries and CMake package for **MinGW-w64 GCC 13** (64-bit), and `bin/cfw-ui-gallery.exe`, a tour of the widgets. |
| `ClannectFramework-0.1.0-linux-x64.tar.gz` | The same for **Linux x64** (GCC 13 or Clang 18), with `bin/cfw-ui-gallery`. Built on Ubuntu 24.04: the gallery needs glibc 2.39 or newer and libX11. |
| `ClannectFramework-0.1.0-macos-arm64-EXPERIMENTAL.zip` | **Experimental**, and only present if the macOS build succeeded: the macOS backend has not been tested on a Mac yet. |
| Source code | Build CFW yourself with any supported compiler. |

The prebuilt libraries only work with the compiler family they were built with (Visual Studio is not supported
yet). If yours differs, build from source or use CMake's FetchContent, as the README shows.

## Using a package

Unpack it anywhere and point CMake at it:

```cmake
find_package(ClannectFramework 0.1 REQUIRED)
target_link_libraries(my_app PRIVATE cfw::app)
```

```sh
cmake -S . -B build -DCMAKE_PREFIX_PATH=/path/to/ClannectFramework-0.1.0-linux-x64
```

## What's in 0.1.0

- **cfw-core, cfw-io:** strings, containers, math, `Variant`, signals, `Result`, logging, JSON, files,
  settings, DEFLATE/zlib.
- **cfw-net:** event loop, TCP, TLS through the operating system, HTTP/1.1 client, WebSocket client and
  server.
- **cfw-image:** PNG, JPEG and WebP codecs, exact to the pixel against the reference decoders.
- **cfw-text:** Unicode 18, a TrueType/CFF font parser, OpenType shaping for every script HarfBuzz shapes,
  text layout, font fallback.
- **cfw-gfx:** a 2D painter with paths, gradients, images, clipping and blend modes; SVG icons.
- **cfw-platform, cfw-ui, cfw-app:** native windows, input methods, drag and drop, clipboard, OpenGL, a full
  widget toolkit, and screen reader support on Windows and Linux.

On Windows, the gallery is not code-signed, so SmartScreen may warn the first time you run it: choose
**More info → Run anyway**.
