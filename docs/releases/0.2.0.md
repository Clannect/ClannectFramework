**Windows installers**: an online installer that downloads the version you choose and tells you about new
releases, and an offline installer with everything inside. Both are built with Clannect Framework itself.

This is a **pre-1.0** release: CFW runs Clannect today, but the API may change between versions.

## Downloads

| File | What it is |
|---|---|
| `ClannectFramework-windows-x64-online-installer.exe` | **Windows, recommended.** Installs any published version for MinGW-w64 GCC 13 (64-bit), and can tell you when a new one is released. |
| `ClannectFramework-0.2.0-windows-x64-offline-installer.exe` | **Windows, no internet needed.** Installs 0.2.0. |
| `ClannectFramework-0.2.0-windows-x64-mingw.zip` | The same Windows package as a zip, for scripts and CI. |
| `ClannectFramework-0.2.0-linux-x64.tar.gz` | Headers, static libraries and CMake package for **Linux x64** (GCC 13 or Clang 18), with `bin/cfw-ui-gallery`. Built on Ubuntu 24.04: the gallery needs glibc 2.39 or newer and libX11. |
| `ClannectFramework-0.2.0-macos-arm64-EXPERIMENTAL.zip` | **Experimental.** The same for **macOS 13.3+ on Apple silicon**. It passes the test suite on GitHub's macOS runners but nobody has used it on a real Mac yet: reports are welcome. |
| Source code | Build CFW yourself with any supported compiler. |

The prebuilt libraries only work with the compiler family they were built with (Visual Studio is not supported
yet). If yours differs, build from source or use CMake's FetchContent, as the README shows.

## Using an installed version

```cmake
find_package(ClannectFramework 0.2 REQUIRED)
target_link_libraries(my_app PRIVATE cfw::app)
```

On Windows, if you let the installer register the version with CMake, that is all. Otherwise, and for the zips,
configure with `-DCMAKE_PREFIX_PATH=<the installed or unpacked folder>`.

## What's new since 0.1.1

- **Windows installers** (online and offline) and a maintenance tool: versions install side by side, per user,
  with no administrator rights. Uninstall them from Windows' Installed apps.
- **cfw-io:** `ZipArchive` and `extractZip`, a zip reader for stored and DEFLATE archives that refuses entries
  escaping the destination. Tested against Python's zipfile and Info-ZIP, and fuzzed.
- **cfw-app:** `chooseFolder`, the system's folder picker (Windows, macOS, zenity/kdialog).
