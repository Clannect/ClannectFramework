The first **macOS** build of Clannect Framework, experimental, alongside Windows and Linux.

This is a **pre-1.0** release: CFW runs Clannect today, but the API may change between versions.

## Downloads

| File | What it is |
|---|---|
| `ClannectFramework-0.1.1-windows-x64-mingw.zip` | Headers, static libraries and CMake package for **MinGW-w64 GCC 13** (64-bit), and `bin/cfw-ui-gallery.exe`, a tour of the widgets. |
| `ClannectFramework-0.1.1-linux-x64.tar.gz` | The same for **Linux x64** (GCC 13 or Clang 18), with `bin/cfw-ui-gallery`. Built on Ubuntu 24.04: the gallery needs glibc 2.39 or newer and libX11. |
| `ClannectFramework-0.1.1-macos-arm64-EXPERIMENTAL.zip` | **Experimental.** The same for **macOS 13.3+ on Apple silicon** (Apple Clang 15 or newer), with `bin/cfw-ui-gallery`. It builds and passes the whole test suite on GitHub's macOS runners, but nobody has used it on a real Mac yet: reports are welcome. |
| Source code | Build CFW yourself with any supported compiler. |

The prebuilt libraries only work with the compiler family they were built with (Visual Studio is not supported
yet). If yours differs, build from source or use CMake's FetchContent, as the README shows.

## Using a package

Unpack it anywhere and point CMake at it:

```cmake
find_package(ClannectFramework 0.1 REQUIRED)
target_link_libraries(my_app PRIVATE cfw::app)
```

```sh
cmake -S . -B build -DCMAKE_PREFIX_PATH=/path/to/ClannectFramework-0.1.1-linux-x64
```

## What's new since 0.1.0

- **macOS (experimental):** the AppKit windows, OpenGL, clipboard, input methods, drag and drop, file
  pickers and accessibility now build with Apple Clang and pass the test suite. Full screen waits for
  macOS's animation before a second change. Resizing back after leaving full screen is not verified on
  the CI machines.
- **Faster startup with system fonts:** listing the installed fonts reads only each font's names instead of
  the whole file, once per program. UI apps start noticeably faster, most of all on macOS.
- Portability fixes found by the first macOS build (types, aggregate initialisation, a Linux-only helper).

## Unsigned apps

The gallery is not code-signed. On Windows, SmartScreen may warn the first time you run it: choose
**More info → Run anyway**. On macOS, Gatekeeper blocks it at first: right-click it and choose **Open**,
or run `xattr -dr com.apple.quarantine ClannectFramework-0.1.1-macos-arm64-EXPERIMENTAL`.
