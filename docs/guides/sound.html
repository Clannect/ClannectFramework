Play sound

Decode WAV, Ogg Vorbis, MP3 and FLAC with cfw-audio, and play the result through the system's default device.

How it fits together

There are three parts, and you connect them yourself:

  • A decoder turns the bytes of a file into samples: interleaved floats.
  • A resampler brings those samples to the rate the device wants.
  • The device calls a function of yours whenever it needs more sound, and you fill its buffer. The device always asks for 48 kHz stereo float.

Link cfw::audio. It needs cfw-core only.

Play a short clip

Decode the whole file once, bring it to 48 kHz once, and keep it in memory:

#include "cfw/audio/AudioDecoder.h"
#include "cfw/audio/AudioDevice.h"
#include "cfw/audio/Resampler.h"

// The format is detected from the bytes.
auto clip = cfw::decodeAudio(bytes);                       // Result<AudioBuffer>: float, interleaved
auto ready = cfw::resample(clip.value(), cfw::AudioDevice::kSampleRate);

// The device pulls 48 kHz stereo float whenever it needs more.
auto device = cfw::AudioDevice::open([&](float *stereo, int frames) { mixer.mix(stereo, frames); });
if (device) device.value()->start();                       // no device: carry on silent

mixer stands for your own code: whatever adds up the sounds that are playing and writes frames stereo frames into stereo.

A machine may have no sound device

AudioDevice::open returns a Result. On a server, in a container or with nothing plugged in, it fails. Check it, and carry on without sound.

Play long music

Do not decode a long file up front. AudioStream::open(bytes) reads a piece at a time and can seek, and StreamResampler converts it block by block.

The example program examples/play-audio does both ways:

cfw-play-audio music.ogg            # decode it all, then play
cfw-play-audio music.ogg --stream   # decode while playing

Formats

FormatChecked against
WAVFiles built in the tests, bit for bit.
FLACThe reference flac encoder's files, bit for bit.
Ogg VorbisFFmpeg's decoder on libvorbis' files, within 2e-5 a sample. Seeking is exact to the sample.
MP3FFmpeg's decoder on LAME's files (MPEG-1, 2 and 2.5), within 1e-4 a sample, with gapless trimming and seeking.

Not supported

  • MPEG Layer I and II, and free-format MP3 streams.
  • Vorbis floor type 0, which only encoders from before 2001 produce.
  • Ogg files with several logical streams: the first one is played.
  • Channel layouts beyond passing every channel through.
Unverified

MP3 intensity stereo is implemented but has not been checked: no encoder at hand produces it.
